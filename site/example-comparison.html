Example comparison

An illustrative walk-through of a single structured-output case through the pipeline. The numbers below are a hand-authored illustration of the intended shape; real, reproducible numbers land on the Results page after the smoke run (Milestone 12).

status: illustrative — replaced by real smoke output at Milestone 12

The case

case_id: structured_json/order_summary
prompt:  "Return an order summary as JSON."
json_schema: { required: [order_id, total_usd, items], ... }

Baseline vs candidate output

baseline  (recorded):   {"order_id":"A-1","total_usd":42.0,"items":3}      # valid
candidate (scripted):   {"order_id":"A-1","total":"42.0","items":3}       # 'total_usd' missing, wrong type

Scored deltas

MetricBaselineCandidateDelta
json_parse_success1.01.00.0
json_schema_validity1.00.0-1.0
field_diff_count02+2
latency_ms180190+10

Resulting flag

RegressionFlag(
  category="structured_output_regression",
  severity="critical",
  metric="json_schema_validity",
  observed=0.0, threshold=1.0,
  explanation="required field 'total_usd' missing; 'total' has wrong type (str, expected number)",
  attribution="app"
)

The latency move (+10 ms) does not flag: it fails the absolute (+50 ms) and relative (+25%) minimums. Only the schema regression fires, so the report leads with the correctness loss, not the noise.
