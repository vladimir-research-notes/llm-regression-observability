Roadmap & research directions

Where the work could go as research, framed honestly as open questions plus what would have to be built and shown. Full text in docs/PAPER_PATH.md. The current scaffold demonstrates none of these yet; it provides the contracts, deterministic ground-truth fixtures, and the detection/report pipeline that make the studies runnable.

Build path (near term)

Milestones 0–13 (see Milestones) deliver the runnable framework: schemas, fixtures, adapters, executor, evaluators, comparison, reports, observability, redaction, integration contracts, and an optional guarded API adapter.

Research directions (longer term)

  1. Statistical detection under stochasticity. Multi-sample adapters; replace threshold flags with significance tests that control a stated false-discovery rate; measure detection power vs sample budget.
  2. Failure clustering & root-cause attribution. Inject k defect types; measure whether clustering recovers k homogeneous groups against a known confusion matrix.
  3. App vs. infra attribution as a measurable claim. Label a set of app/infra incidents; report precision/recall and the asymmetric cost of each error type.
  4. Process-metric validity. Do retries / failed tool calls / sequence drift predict outcomes users care about, or are they gameable proxies? Calibrate severity accordingly.
  5. Grounding without a semantic model. Benchmark the stdlib evidence scorers against a learned-entailment baseline; state precisely where the placeholder must be replaced.
  6. Cross-system trace portability. Realize the import contracts against a code-agent runtime, BioAgentBench, BioScientist OS, and agent-control-bench; run the same detectors and reports on imported traces.

Non-claims

Each direction needs its own experiment, dataset, and write-up before any empirical claim is made. Nothing above is asserted by the current repository.
