Roadmap & research directions

Where the work could go as research, framed honestly as open questions plus what would have to be built and shown. Full text in docs/PAPER_PATH.md. The repository demonstrates none of these yet; it provides the contracts, deterministic ground-truth fixtures, and the detection/report pipeline that make the studies runnable.

Build path (near term)

Milestones 0–12 (see Milestones) have delivered the runnable framework: schemas, fixtures, adapters, executor, evaluators, comparison, reports, observability, redaction, integration contracts, an optional guarded API adapter, and documentation whose numbers are under test. Milestone 13 is a final gate run and hygiene check — no new capability.

Product path (shortest useful step)

The CI gate already exists. llmreg compare --fail-on critical exits 1 on a critical regression, so a model, prompt, or tool bump can be blocked at the pull request, with the rendered report attached. What that needs before it is worth running against a real system is direction 1 below: thresholds chosen by hand on synthetic fixtures will misfire on sampled models, and a gate that misfires gets turned off.

Research directions (longer term)

  1. Statistical detection under stochasticity. Multi-sample adapters; replace threshold flags with significance tests that control a stated false-discovery rate; measure detection power vs sample budget.
  2. Failure clustering & root-cause attribution. Inject k defect types; measure whether clustering recovers k homogeneous groups against a known confusion matrix.
  3. App vs. infra attribution as a measurable claim. Label a set of app/infra incidents; report precision/recall and the asymmetric cost of each error type.
  4. Process-metric validity. Do retries / failed tool calls / sequence drift predict outcomes users care about, or are they gameable proxies? Calibrate severity accordingly.
  5. Grounding without a semantic model. Benchmark the stdlib evidence scorers against a learned-entailment baseline; state precisely where the placeholder must be replaced.
  6. Cross-system trace portability. The import contracts exist (Milestone 10) and are exercised on committed synthetic examples: an imported trace is scored, compared and reported by the unchanged pipeline. What remains is first contact — run the importers against real emitters from a code-agent runtime, BioAgentBench, BioScientist OS and agent-control-bench, and measure how much of each declared shape survives. The importers are hypotheses until then; the four rules (account for every field, invent no measurement, guess no attribution, import no secret) are what should survive the contact.

Non-claims

Each direction needs its own experiment, dataset, and write-up before any empirical claim is made. Nothing above is asserted by the current repository.
