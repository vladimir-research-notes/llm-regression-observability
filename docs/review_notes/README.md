# Human review notes

**placeholders** created by the milestone runner so a human can review later —
the agent does **not** wait for review and does **not** claim review happened.

Template:

```
Human review: <milestone title>

TL;DR

What changed

What should be checked later

Technical risks

Commands to verify

Human feedback
<!-- Human will fill this later. -->
```
